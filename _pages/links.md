## Tools and resources

- **[FSR Lab Computational Resources](https://fsr-dictionary.readthedocs.io/en/latest/)** — a hub for the lab's computational tools: PEGG, H2M, and the sensor analysis pipeline, each with documentation, code, and usage examples.
- **[H2M](https://human2mouse.com/)** — web portal for modeling human genetic variants in the mouse genome, with a database of over three million human–mouse mutation pairs.
- **[PEGG](https://pegg30.readthedocs.io/en/latest/)** — documentation for the Prime Editing Guide Generator.
